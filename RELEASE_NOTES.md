## Версия 0.8.2 (2026-07-21)

*Исправлено распознавание Hyper-комбинаций после удержания CapsLock.*

### 🐛 Исправления ошибок

- Устранён ложный сброс Hyper-режима перед обработкой второй клавиши: подавленный `CapsLock DOWN` больше не проверяется через недостоверный `GetAsyncKeyState` внутри low-level keyboard hook
- Калиброванные клавиши, включая фонетические раскладки, снова отправляют назначенные комбинации, например `CapsLock + G` → `Ctrl + F19`

### 🛠 Улучшения

- Добавлен regression-тест полного пути от событий keyboard hook до отправки назначенной Hyper-комбинации

## Версия 0.8.1 (2026-07-21)

*Исправлена отправка Hyper-комбинаций и подготовлен воспроизводимый Windows-релиз.*

### 🐛 Исправления ошибок

- В Hyper-комбинации снова фактически входит `Shift`; ранее интерфейс показывал четыре модификатора, но `SendInput` отправлял только три
- Автоповтор CapsLock больше не сбрасывает состояние Hyper и не переключает регистр после удержания
- Одиночный `CapsLock UP` после перезапуска hook больше не превращается в ложный tap
- При смене фокуса на blacklist-процесс и при отключении приложения состояние удерживаемых клавиш корректно сбрасывается
- Исправлены pointer-sized типы WinAPI и остановка message loop на 64-битной Windows
- Устранена одновременная работа двух keyboard hook, вызывавшая двойную отправку хоткеев
- Потерянный CapsLock KEYUP после UAC, блокировки или смены desktop больше не оставляет Hyper включённым
- Keyboard hook автоматически восстанавливается после тихого снятия Windows по timeout
- Сортировка таблицы больше не может перепривязать кнопки к другой клавише
- Режим калибровки не подавляет KEYUP клавиш, нажатых до начала записи
- Запрещён одновременный запуск двух экземпляров Hyperion

### 🛠 Улучшения

- Добавлен единый FIFO-worker отправки ввода вместо отдельного потока на каждое событие
- Сохранение `config.json` и `settings.json` выполняется через атомарную замену файла
- Главное окно разделено на runtime, settings и keys модули
- Автозагрузка dev-режима использует `pythonw.exe` и безопасный запуск VBS без shell
- Добавлены русские стандартные переводы Qt, автоматические тесты и release quality gate
- Обновлены PyInstaller spec, post-build manifest, legal bundle, installer и portable deploy workflow
- Исправлены подписи столбцов и адаптивная ширина кнопок на вкладке клавиш
- Foreground-процесс кэшируется вне hook callback; blacklist использует ограниченные права доступа
- Пауза на 10 секунд больше не отменяет последующее ручное выключение пользователя
- Повреждённые config/settings сохраняются для восстановления, а окно возвращается на доступный монитор
- Обновление журнала ограничено десятью перерисовками в секунду вместо полной перерисовки на событие
- Добавлена настраиваемая совместимость с injected-вводом для RDP и экранных клавиатур
