# Доступ к исходному коду

Исходный код Hyperion доступен в публичном репозитории:

<https://github.com/Frommer-droid/Hyperion>

Исходники Qt for Python и инструкции по самостоятельной сборке доступны в
официальном репозитории:

<https://code.qt.io/cgit/pyside/pyside-setup.git/>

Версии runtime-компонентов конкретной сборки записаны в
`RUNTIME_MANIFEST.json` рядом с `Hyperion.exe`.
